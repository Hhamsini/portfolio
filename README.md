## Open in VS Code
1. Unzip the folder.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html`.
5. Choose **Open with Live Server**.

## Publish free using GitHub Pages
1. Create a repository called `hhamsini-portfolio`.
2. Upload all files and all image files.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

## Publish free using Vercel
1. Sign in with GitHub.
2. Import the repository.
3. Deploy using default settings.
